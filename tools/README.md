# Profile README sources

`profile/README.md` and every image in `profile/assets/` are generated by these
scripts. Nothing is drawn by hand.

    python3 tools/concept_c.py      # writes ./c/README.md and ./c/assets/*.svg

They read the fonts and the current app icons from a checkout of `daifukus/DFK`
(`DFK` and `DAIFUKUS` paths in `common.py`). Colours, typefaces and headlines of
each app card come from that app's own landing page (see `apps_cards.py`). Fonts
are embedded in the SVGs, so GitHub shows the real faces; animations respect
`prefers-reduced-motion`.
