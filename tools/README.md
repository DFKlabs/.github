# Profile README sources

`profile/README.md` and every image in `profile/assets/` are generated by these
scripts. Nothing is drawn by hand.

    python3 tools/concept_c.py profile   # rewrites profile/README.md and profile/assets/*.svg
    python3 tools/concept_c.py           # same, into tools/c/ to compare first

They read the fonts and the current app icons from a checkout of `daifukus/DFK`
(the `DFK` and `DAIFUKUS` environment variables, or the default paths in
`common.py`). Colours, typefaces and headlines of each app card come from that
app's own landing page (see `apps_cards.py`). Fonts are embedded in the SVGs, so
GitHub shows the real faces; animations respect `prefers-reduced-motion`.

The README is one continuous black panel. GitHub can't colour the page behind
it, so every image paints its own background and margins (`PANEL`, `PAD`,
`slot()` and `tile()` in `common.py`), and the README sets the images edge to
edge: nothing between them, and `align="top"` on each so no baseline gap shows.
What each app is, in a sentence, goes in the alt text.
